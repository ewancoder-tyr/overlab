# Ubiquitous language

The words the code, the screens and these documents use, each with one meaning.

| Term                     | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Exercise**             | A named movement in the catalog with muscle involvements, form notes, warm-up guidance and a load type.                                                                                                                                                                                                                                                                                                                                                |
| **Form**                 | Correct execution of an exercise. Text on the exercise. Not the same as technique.                                                                                                                                                                                                                                                                                                                                                                     |
| **Technique**            | How a rep is executed: full, long-length partial, paused, and so on.                                                                                                                                                                                                                                                                                                                                                                                   |
| **Rep Group**            | Consecutive reps of one exercise, one technique and one load.                                                                                                                                                                                                                                                                                                                                                                                          |
| **Set**                  | One bout of work before resting: an ordered list of rep groups. Its identity is the id of its `SetPerformed` event.                                                                                                                                                                                                                                                                                                                                    |
| **Load**                 | The number as entered plus its unit (`kg` or `lb`). Stored as entered, never converted. For per-side exercises (dumbbells) it is the load per hand.                                                                                                                                                                                                                                                                                                    |
| **Added Load**           | For bodyweight exercises the load is signed: `+10` weighted, `0` plain, `-20` assisted.                                                                                                                                                                                                                                                                                                                                                                |
| **Effort**               | "Reached failure", "light", "easy" or reps in reserve (RIR). Optional, per set; absent means the usual, close to failure (about 1 RIR).                                                                                                                                                                                                                                                                                                                |
| **Warm-up**              | A set of kind `warmup`. Excluded from volume and progression.                                                                                                                                                                                                                                                                                                                                                                                          |
| **Light Set**            | A working set marked "light": done easy on purpose, reserve unknown. A kind of effort, never with failure. Compared, recorded and hyped like any working set; counts as the light set weight in weekly volume. A mint dot on its tile.                                                                                                                                                                                                                 |
| **Easy Set**             | A working set marked "easy": far from failure on purpose (daily push-ups, a ramp-up over weeks). A kind of effort, below light. Always worth 0 in weekly volume; compared, recorded and given experience like a working set (unlike a warm-up). A hollow mint ring on its tile.                                                                                                                                                                        |
| **Easy Session**         | Derived: a session whose working sets are all easy. It aims to match last time, and the stall count skips it. See the easy session rule (`docs/rules/training.md`).                                                                                                                                                                                                                                                                                    |
| **Standalone Set**       | A set done outside any workout (`standalone` on `SetPerformed`). It touches no workout, rest, workout time or program day, and counts everywhere else. Its sessions are per exercise and compared only among themselves. See the standalone set rule (`docs/rules/training.md`).                                                                                                                                                                       |
| **Setup**                | A specific machine or gym for an exercise. Progression is compared only within the same setup. Every set is on its exercise's default setup: the app cannot define another one yet.                                                                                                                                                                                                                                                                    |
| **Workout**              | Derived, never stored: consecutive sets and cardio bouts with less than 3 hours between them. Standalone sets are in no workout.                                                                                                                                                                                                                                                                                                                       |
| **Void**                 | Marks a set as a mistake. To correct a set, void it and re-log with the original `occurredAt`.                                                                                                                                                                                                                                                                                                                                                         |
| **Favorite**             | An exercise the user starred in the Catalog. Only favorites (and the exercises of programs) are offered on the Train page. Logging an exercise does not make it a favorite.                                                                                                                                                                                                                                                                            |
| **Program**              | The list of exercises the user prepared for each day they train: a name, a schedule, a reminder and one or more program days. A template and a calendar rule only: sets never refer to it. See the program rule (`docs/rules/training.md`).                                                                                                                                                                                                            |
| **Rest**                 | Derived, never stored: the time since the latest set (any exercise, warm-ups included; cardio and standalone sets neither start nor reset it). Counts up. Shown only within the idle limit of that set.                                                                                                                                                                                                                                                |
| **Rest Alert**           | When rest reaches this time on the current exercise's logging screen, the phone buzzes once and the rest flashes yellow. A preference, default 1:00, from 0:15 to 5:00 in steps of 15 s, or off (0). Rest keeps counting. Set under Settings, Advanced.                                                                                                                                                                                                |
| **Switch Rest Alert**    | The rest alert everywhere else (the Train page, another exercise, any other page): moving on takes a longer rest. A preference, default 3:00, from 0:15 to 10:00 in steps of 15 s, or off (0). Set under Settings, Advanced.                                                                                                                                                                                                                           |
| **Current Exercise**     | Derived, never stored: the primary exercise of the latest set, while its rest is shown. Highlighted on the Train page; its screen is where the rest alert applies.                                                                                                                                                                                                                                                                                     |
| **Workout Time**         | Derived, never stored: from the first activity of the workout in progress to now while it runs, and to its last activity once stopped.                                                                                                                                                                                                                                                                                                                 |
| **Idle Limit**           | 10 minutes with nothing logged. After it, rest is not shown and workout time stops. A display rule only, not the 3-hour gap that separates workouts.                                                                                                                                                                                                                                                                                                   |
| **Program Day**          | One day of a program (Day 1, Day 2, by position): an ordered list of exercises. A workout is a program day only when the user chose it (`ProgramDayChosen`); the day that comes next is the one after the day done last.                                                                                                                                                                                                                               |
| **Involvement**          | How much an exercise trains a muscle group, from above 0 to 1. 1 is the primary mover.                                                                                                                                                                                                                                                                                                                                                                 |
| **Cardio**               | An exercise with no involvements (running, cycling). It never counts towards weekly volume and is logged as cardio bouts, not as sets.                                                                                                                                                                                                                                                                                                                 |
| **Cardio Bout**          | One stretch of a cardio exercise: a run, a ride. Records distance, time and calories, each optional, at least one present. Its identity is the id of its `CardioPerformed` event.                                                                                                                                                                                                                                                                      |
| **Cardio Kind**          | What a cardio exercise records (`cardioKindOf`): `distance` (distance, time, calories; the default), `treadmill` (the same in segments, each with an incline) or `timed` (time only: Sauna).                                                                                                                                                                                                                                                           |
| **Segment**              | One stretch of a treadmill session at one incline: a cardio bout (`CardioPerformed`) with an `incline`. A session's segments are added up like any bouts.                                                                                                                                                                                                                                                                                              |
| **Incline**              | The incline of a treadmill segment, stored exactly as the machine showed it: 0 (flat) to 40 in steps of 0.5. Read as percent grade. Should that reading change, only labels and the climb formula change, never the stored number.                                                                                                                                                                                                                     |
| **Climb**                | Derived, never stored: metres climbed in a treadmill session, each segment's distance times its incline in percent, added up. 0 for a flat session. The third axis of treadmill progression.                                                                                                                                                                                                                                                           |
| **Logging in the past**  | Going back to a moment of an earlier day to log what was done then (History, "Log on this day"). The app's clock is shifted there, in memory only; events get that `occurredAt` and the real `recordedAt`. Not the test date: these events are real and sync.                                                                                                                                                                                          |
| **Speed**                | Distance divided by time, in km/h. Derived for display and comparison, never stored.                                                                                                                                                                                                                                                                                                                                                                   |
| **Weekly Volume**        | Working sets per muscle group over the target window (a rolling 7 days by default), weighted by involvement. A mixed-exercise set is split by each exercise's share of its reps. A light set counts as the light set weight, an easy set as 0. Reps are totalled the same way (in full) and shown alongside.                                                                                                                                           |
| **Volume Target**        | A preference: the minimum of weighted sets per muscle group in the target window, default 10, from 4 to 20. The maximum is always double the minimum (10 gives 10 to 20). One target for every muscle group. A muscle group is under, within or over it.                                                                                                                                                                                               |
| **Light Set Weight**     | What a light set is worth in weekly volume, in percent of a set. A preference, default 50, from 0 (like a warm-up) to 100 (like any set) in steps of 10. Set under Settings, Advanced.                                                                                                                                                                                                                                                                 |
| **Weekly Cardio**        | Derived, never stored: the minutes of all non-voided cardio bouts over the target window, summed across every cardio exercise, with a breakdown per exercise. The cardio counterpart of weekly volume.                                                                                                                                                                                                                                                 |
| **Cardio Goal**          | The minutes of cardio to reach in the target window. A preference, default 150, from 30 to 600 in steps of 15. A minimum only: weekly cardio is under or reached, never over.                                                                                                                                                                                                                                                                          |
| **Target Window**        | How many days the volume target and the cardio goal are counted over: "20 sets per 14 days". A preference, default 7, from 3 to 28. Rolling whole days of 24 hours back from now, never calendar days. The targets are not scaled: a longer window is a different target, not another view. Set under Settings, Advanced.                                                                                                                              |
| **Training Focus**       | What the user trains: `both` (default), `lifting` or `cardio`. A preference. It only hides things (Week, Train, Catalog, Advanced settings, rest); it never changes what is logged, counted or synced.                                                                                                                                                                                                                                                 |
| **Language**             | The language the app speaks: `en` or `ru`. A preference; until one is chosen the app follows the browser's language. Reminders and update notices are sent in it.                                                                                                                                                                                                                                                                                      |
| **Color Scheme**         | How the app looks: `dark` (default, black and yellow) or `light` (the same look on a pale surface). A preference, under Settings. It only changes colours.                                                                                                                                                                                                                                                                                             |
| **Schedule**             | The days a program is done on: fixed days of the week, or every N days counted from a start date. Fixed weekdays never move; "every N days" counts on from the day the program was really done.                                                                                                                                                                                                                                                        |
| **Reminder**             | A notification on each day of a program, at the reminder time set in Settings (default 15:00) or at the program's own time; a program can also have none. Per device: whether reminders are on is a fact about one device (its push subscription), not an event.                                                                                                                                                                                       |
| **Solo Program**         | A program done outside workouts (push-ups every morning): a single day of one or more exercises, logged as standalone sets. Every exercise done standalone lately is one, made by the user or not. See the program rule (`docs/rules/training.md`).                                                                                                                                                                                                    |
| **Hype**                 | A line for the reminder: what was last done on an exercise of the program's next day and a bolder number to go for (for cardio, the same session to match). Not the progression rule, which one extra rep satisfies.                                                                                                                                                                                                                                   |
| **Personal Record**      | Derived, never stored, and a standing rather than an event: per exercise and setup there is one **weight record**, the first working set ever at the heaviest load (any reps), and one **rep record**, the first working set with the most full reps at that same load. One set may hold both. Lighter sets never hold one. For cardio, a whole session that no earlier one matches: a distance, climb, speed, calories, burn-rate or duration record. |
| **Record Table**         | Derived: for one exercise and setup, the best reps ever done at each load where nothing heavier was done for as many reps. These are the numbers to beat.                                                                                                                                                                                                                                                                                              |
| **Stall**                | Derived, never stored: an exercise whose last N finished sessions on its current setup (N = the stall threshold) each failed to beat the session before (`same` or `down`). Lifting only: cardio never stalls. A warning, not a verdict on the lifter.                                                                                                                                                                                                 |
| **Match**                | A cardio session that is the same as the one before on everything compared (same distance, same speed). Matching or beating last time is the aim of every cardio session; see the cardio match rule (`docs/rules/cardio.md`).                                                                                                                                                                                                                          |
| **Stall Threshold**      | How many sessions in a row without progress make a stall. A preference, default 3, from 2 to 10, or off (0). Set under Settings, Advanced.                                                                                                                                                                                                                                                                                                             |
| **Stall Involvement**    | How much an exercise must involve a muscle group for its stall to mark that muscle group: more than this, in percent. A preference, default 50 (so a stalled bench press marks chest, not triceps at 0.5; a dip at 0.8 and 0.8 marks both), from 0 (every involved muscle) to 90 in steps of 10. Set under Settings, Advanced.                                                                                                                         |
| **Volume Breakdown**     | Derived: for one muscle group, the weighted sets each exercise gave it in the target window, largest first. They add up to its weekly volume.                                                                                                                                                                                                                                                                                                          |
| **Stalled Muscle Group** | Derived, never stored: a muscle group with at least one stalled exercise in its volume breakdown that involves it by more than the stall involvement. An orange dot on its Week gauge. A warning, like the stall itself.                                                                                                                                                                                                                               |
| **Volume Advice**        | Derived: what a stalled muscle group's volume status suggests. **Add sets** (under target), **room to add** (within, every direct exercise stalled), **back off** (over, every direct exercise stalled), otherwise only **the exercise** is named. A hint, never a verdict.                                                                                                                                                                            |
| **Progression**          | Comparison of a set with the matching set of the previous session of the same exercise and setup, whatever workout or program day that was in.                                                                                                                                                                                                                                                                                                         |
| **Cloud Copy**           | The server's copy of a signed-in user's event log, keyed by their Google account. The union of everything their devices have pushed.                                                                                                                                                                                                                                                                                                                   |
| **Pending**              | An event in the local log that the server has not yet confirmed. Nothing pending means the device is fully backed up.                                                                                                                                                                                                                                                                                                                                  |
| **Experience (XP)**      | Derived, never stored: points for working sets and for progress (see `docs/rules/experience.md`), per exercise and in total, counted from the latest `ProgressReset`. Shown only while gamification is on.                                                                                                                                                                                                                                             |
| **Level**                | Derived from experience on a quadratic curve: level L needs `scale × (L − 1)²` in total, 50 for the character, 10 for an exercise. Every level costs a fixed amount more than the one before.                                                                                                                                                                                                                                                          |
| **Title**                | The character's name for its level, gym-themed, one per level from 1 (Fresh Meat) to 30 (Legend of the Lab), kept beyond 30 (`gamification/domain/title.ts`). Shown beside the level in the Week summary and in the level-up burst. Russian titles have no gendered forms.                                                                                                                                                                             |
| **Gamification**         | A preference, off by default: whether experience and levels are shown (a slim level summary atop the Week page, details at its bottom). It only hides; experience is derived from the log either way.                                                                                                                                                                                                                                                  |
| **Leaderboard**          | Everyone who chose to take part, ranked by experience: Google name and picture, level and title. Only those taking part see it. Needs gamification on and a Google sign-in. Not an event: taking part is a row on the server.                                                                                                                                                                                                                          |
| **Follow**               | One account on the leaderboard asking to hear about another's sets: a bell on its row. One-sided, it does nothing and is shown to nobody but the follower. Not an event: a row on the server. At most 20 per account. See Buddies (`docs/leaderboard.md`).                                                                                                                                                                                             |
| **Buddy**                | Derived on the server, never shown: someone you follow who follows you back. Buddies are pushed a roast about each set and cardio bout the other logs.                                                                                                                                                                                                                                                                                                 |
| **Generation**           | A counter on the cloud copy, bumped by "Delete everything". A device on an older generation erases itself on its next sync.                                                                                                                                                                                                                                                                                                                            |
