# Before 1.0

OverLab was built as a series of beta versions in November 2026. Version 1.0.0 started
the release notes afresh (`src/app/release-notes.json`) and the repository with a single commit, so
this page is what remains of that history. Some rules and code comments refer to these versions,
most often to the "0.3.0 day", when cardio was briefly logged as sets (see `docs/rules/cardio.md`).

- **0.17.0** (2026-11-25): Buddies: follow a friend on the leaderboard and, once they follow you
  back, you both hear about each other's sets.
- **0.16.0** (2026-11-25): Treadmill with segments and incline, Sauna, solo reminders, and a History
  you can correct: delete old entries or log on a past day.
- **0.15.0** (2026-11-15): Easy and solo sets for training outside workouts, and a History page with
  every day you trained.
- **0.14.0** (2026-11-14): Experience and levels: turn training into a game, with titles,
  celebrations and a leaderboard.
- **0.13.0** (2026-11-13): A light colour scheme: the same black-and-yellow look, printed on paper.
- **0.12.0** (2026-11-13): Every exercise has new drawings: one tough lifter in a bold retro manual
  style.
- **0.11.0** (2026-11-13): Targets over any number of days, a rest clock that flashes like
  lightning, and a tidier Settings and Data page.
- **0.10.0** (2026-11-13): The Week page shows which muscles have stalled, cardio aims to match last
  time, and tabs react to every tap.
- **0.9.0** (2026-11-13): Light sets, two rest alerts and a tidier logging screen.
- **0.8.0** (2026-11-13): A weekly cardio goal, and the app shows only what you train.
- **0.7.0** (2026-11-12): A rest timer, personal records and stall warnings.
- **0.6.0** (2026-11-12): Switching tabs is instant again.
- **0.5.0** (2026-11-12): OverLab speaks Russian, and your log can be backed up to the cloud.
- **0.4.0** (2026-11-12): Cardio: track distance, time and calories, with progress charts.
- **0.3.0** (2026-11-12): Exercise drawings on the logging screen.
- **0.2.0** (2026-11-12): Workout plans, favorites and 16 new exercises.
- **0.1.0** (2026-11-12): The first version of OverLab.
